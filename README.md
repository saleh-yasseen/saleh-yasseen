⭐ Featured Project

📰 "Arabic News Agentic RAG" (https://github.com/saleh-yasseen/Arabic_News_Agentic_RAG)

A completed agentic RAG system for Arabic news research, focused on retrieval quality and grounded answers.

Stack: LangGraph · AraBERT · BM25 · RRF · Cohere Reranking · Qdrant · FastAPI · Streamlit

Recall@5

"0.56" Dense → "0.63" BM25 → "0.74" Hybrid → "0.85" Hybrid + Reranking

Built with an evaluation harness covering retrieval metrics, router accuracy, LLM-as-judge scoring, and latency analysis.
